# PP Lab — Paradox & Possibility Lab

悖论与可能性实验室。一个条件驱动的哲学思想实验工作台：把主张、前提、反驳和修订放进同一份可操作状态里。

在线预览：https://kirmarainch.github.io/pp-lab/

## 定位

PP Lab 面向分析哲学的方法，当前聚焦三个相邻领域：

- 心智哲学：功能主义、中文屋、解释鸿沟、现象意识、哲学僵尸；
- 认识论：可验证性、理由空间、解释与理解；
- 科学技术哲学：机制解释、认识论不透明性、黑箱模型与可解释性。

它不是聊天机器人，也不是通用的「AI 神谕」。当前版本没有模型调用，探针由本地规则和立场卡驱动；重点在把论证变成可操作、可回看、可修订的对象，而不是替用户给出结论。

## 核心体验

1. 在黑箱室场景中提出一个判断（claim）；
2. 开关「可解释性 / 可验证性 / 有理由」等前提，观察 3D 场景与标注的真实变化；
3. 选择一个哲学立场，运行探针；探针会指向一条具体前提，并在左侧条件栏标出目标；
4. 回应、修改前提或保留异议；每次动作写入带理由的版本；
5. 在思想星图中查看相关理论、案例与来源，区分论证相似、反例、支持、共同议题和未经证实的潜在关联；
6. 回溯历史，或导出实验档案。

## 已实现

- **黑箱室 3D 舞台**：React Three Fiber 场景，条件驱动材质、光路与实体；相机预设可切换；WebGL 不可用时用同一份 SceneSpec 渲染 2D SVG。
- **SceneSpec 1.0**：实体、条件、绑定、注释、相机预设的可校验数据结构；条件与场景属性通过声明式 binding 连接。
- **判断与立场**：claim 输入；三张领域立场卡（功能主义、生物自然主义、机制解释），包含核心承诺、常见反驳、局限与来源，并标明「基于其思想的模拟视角」。
- **探针**：本地规则生成；选择立场后，探针针对具体条件前提，并带来源；支持回应、修改前提、保留异议，以及快照过期提示。
- **反例轨道**：回应 / 修订 / 保留都会生成版本；支持手动保存版本与回溯，回溯本身也留档。
- **思想星图**：场景 / 星图切换；12 个外部节点、18 条关系边、六种关系类型；节点与边详情、来源链接、潜在关联免责声明；中心实验卡实时读取主张和条件。
- **本地持久化**：IndexedDB（Dexie）；JSON 导出已接通，导入待补。
- **明暗双主题与响应式外壳**：浅色陶瓷 / 深色石墨工作台，3D、2D 与星图同步切换；桌面与手机布局。

## 设计原则

- **同一份实验状态**：3D、星图、探针、版本轨道和导出都读取同一份实验与修订数据，不各自编造故事。
- **不替用户下结论**：场景展示设定与关系，不把发光或变暗编码成「理论被证明」；探针是批评，不是裁决。
- **来源与不确定性**：星图关系必须标注类型；历史影响必须有来源；潜在关联明确标注未经文献确认。
- **修订留痕**：记录条件快照、主张、立场、探针与理由，而不是只保存最后一次结果。
- **本地优先**：没有账号和后端，实验数据留在浏览器；静态部署，便于演示与分享。

## 技术架构

- Vite 8 + React 19 + TypeScript 7
- React Three Fiber / three.js（3D 舞台与程序化材质）
- Zustand（实验状态与串行写入队列）
- Zod（SceneSpec、探针、版本与星图数据校验）
- Dexie / IndexedDB（本地持久化）
- CSS 自定义属性 + Tailwind CSS v4（双主题与响应式）
- GitHub Actions + GitHub Pages（静态部署）

## 数据模型

- `SceneSpec`：实体、条件、条件到实体属性的 binding、相机预设、注释；条件变化通过 `resolveScene` 解析为场景状态。
- `Probe`：立场、条件快照、主张快照、目标条件、目标前提、异议、追问、状态与回应。
- `Revision`：版本号、标签、理由、时间与完整快照；回溯会生成新版本而不是覆盖历史。
- `StarMap`：节点、边、来源与关系类型；中心实验节点由当前 `Experiment` 现场生成。

## 部署到 GitHub Pages

仓库包含 `.github/workflows/deploy.yml`。推送到 `main` 后会自动构建 `dist/` 并发布到 GitHub Pages；仓库 **Settings → Pages** 的 Source 需设为 **GitHub Actions**。

## 内容与来源

- 场景标题、对象名称、条件文案与注释：`src/lib/seed.ts`
- 立场卡与探针文案：`src/lib/content.ts`
- 星图节点、关系与来源：`src/lib/starmap.ts`
- 星图来源以 Stanford Encyclopedia of Philosophy 条目和经典文献为主，链接可点击核查；关系判断与立场措辞仍是可编辑草案，不宣称「原创性已认证」或「全球首创」。

## 数据与隐私

- 当前没有模型调用，也没有任何 API key。
- 实验状态只写入浏览器 IndexedDB；导出的 JSON 只包含实验与版本数据。
- 后续若接入模型：密钥只保留在当前会话，不进入导出、日志或错误报告；请求前先核对计价字段并取得明确批准；自定义端点需防止访问本地与内部网络资源。

## 已知边界与下一步

- 立场卡与星图文案是草案，等待最终定稿。
- 探针由本地规则生成，尚未接入真实模型；没有 BYOK。
- 尚未实现自定义 3D 场景编辑、自然语言到 SceneSpec、导演模式与逐幕回放、相似性/潜在贡献报告、更多场景模板。
- 星图桌面端缩放/拖拽尚未实现，移动端目前使用滚动查看。
- 没有正式测试矩阵、录屏测试或外部内测；验证以本地构建、浏览器检查与截图为准。
