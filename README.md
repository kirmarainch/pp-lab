# PP Lab — Paradox & Possibility Lab

悖论与可能性实验室。一个跑在浏览器里的思想实验工作台。

在线预览：https://kirmarainch.github.io/pp-lab/

这个项目不想再做一个人格化的哲学聊天框。它更像一张实验台：你先写下自己的判断，开关几条前提，看 3D 场景怎么变；再让一个立场来挑毛病，决定回应、修改还是保留；最后在星图里查相关理论和来源，把这次修订留在轨道上。

它现在没有接模型，也没有账号和后端。探针由本地规则和立场卡生成，实验数据存在浏览器里。换一台机器可以从头开始，也可以用导出功能带走自己的实验档案。

## 为什么是分析哲学

分析哲学不是题材，是方法。先把前提摆出来，再看反例打在哪，最后把修改理由留下来。PP Lab 把这种方法用在黑箱和不透明系统上，目前主要涉及三块：

- 心智哲学：功能主义、中文屋、解释鸿沟、现象意识、哲学僵尸。
- 认识论：可验证性、理由空间、解释与理解。
- 科学技术哲学：机制解释、认识论不透明性、黑箱模型与可解释性。

这不是“AI 神谕”。场景只展示设定和关系，不把发光或变暗当成“理论被证明”；探针是批评，不是裁决。你可以保留异议，让争论停在“承诺已经清楚，但分歧还在”的地方。

## 现在能做什么

打开页面，左边是前提，中间是黑箱室，右边是判断和探针，底部是版本轨道。

黑箱室是 React Three Fiber 场景。开关「可解释性 / 可验证性 / 有理由」，材质、光路和标注会跟着变；相机有三个预设。WebGL 不可用时，同一份 SceneSpec 会降级成 2D SVG。

判断区可以写 claim，也可以从三张立场卡里选一个：功能主义、生物自然主义、机制解释。每张卡有核心承诺、常见反驳、局限和来源，并注明这是基于其思想的模拟视角，不是本人发言。

探针会从当前立场里挑一条异议，指向一条具体前提。左侧对应的条件会亮起琥珀色的「目标」，探针卡里也能看到目标条件和来源。你可以回应、修改前提或保留异议；每次动作都会生成一个带理由的版本。

星图里有 12 个外部节点和 18 条关系边。关系分六类：历史影响、论证相似、反例、支持、共同议题、潜在关联。点节点或边可以看解释和来源；「潜在关联」会明确写“尚未找到文献支持”。

白天和夜晚两套主题，桌面和手机都能用。数据存在 IndexedDB 里，JSON 导出已经能用，导入还没做。

## 所有视图共用一份状态

3D 场景、星图、探针、版本轨道和导出读的是同一份实验与修订数据。条件一变，探针快照会过期；回溯会生成新版本，不会覆盖旧记录。这样视频里的每个画面都能对得上，不会出现 3D 讲一套、星图讲另一套的情况。

## 技术栈

- Vite 8 + React 19 + TypeScript 7
- React Three Fiber / three.js
- Zustand（实验状态和串行写入队列）
- Zod（SceneSpec、探针、版本、星图数据校验）
- Dexie / IndexedDB
- CSS 自定义属性 + Tailwind CSS v4
- GitHub Actions + GitHub Pages

## 数据模型

SceneSpec 描述实体、条件、条件到实体属性的 binding、相机预设和注释。`resolveScene` 把条件和 binding 解析成场景状态。

Probe 记录立场、条件快照、主张快照、目标条件、目标前提、异议、追问、状态和回应。

Revision 保存版本号、标签、理由、时间和完整快照。回溯会新增一个版本，不会覆盖历史。

StarMap 保存节点、边、来源和关系类型；中心实验节点从当前 Experiment 现场生成，不写死。

## 本地开发

```bash
npm install
npm run dev        # 本地开发
npm run typecheck  # TypeScript 检查
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览生产构建
```

## 部署到 GitHub Pages

仓库包含 `.github/workflows/deploy.yml`。推送到 `main` 后会自动构建 `dist/` 并发布到 GitHub Pages；仓库 **Settings → Pages** 的 Source 需要设成 **GitHub Actions**。

## 内容与来源

- 场景标题、对象名称、条件文案和注释：`src/lib/seed.ts`
- 立场卡和探针文案：`src/lib/content.ts`
- 星图节点、关系和来源：`src/lib/starmap.ts`

星图来源主要是 SEP 条目和经典文献，链接可以直接打开。关系判断和立场措辞还是草案，你可以改；这里不声称“原创性已认证”或“全球首创”。

## 数据与隐私

- 当前没有模型调用，也没有 API key。
- 实验状态只写进浏览器 IndexedDB；导出的 JSON 只包含实验和版本数据。
- 以后接模型的话，密钥只留在当前会话，不进入导出、日志或错误报告；请求前先核对计价字段并取得明确批准；自定义端点要防止访问本地和内部网络资源。

## 还没做的

- 立场卡和星图文案是草案，等最终定稿。
- 探针还是本地规则，没有接模型，也没有 BYOK。
- 自定义 3D 场景、自然语言到 SceneSpec、导演模式、逐幕回放、相似性报告、更多场景模板都没做。
- 星图桌面端还不能缩放和拖拽；手机上目前是滚动查看。
- 验证主要靠本地构建和浏览器检查，没有正式测试矩阵，也没有外部内测。
