# PP Lab — 悖论与可能性实验室

一个跑在浏览器里的哲学思想实验工具。

在线使用：https://kirmarainch.github.io/pp-lab/

不需要注册，不需要下载。打开网页就能用。你可以连接自己的 AI（可选），也可以完全离线使用内置内容。

## 这是什么

想象你有一个观点，比如「如果一台机器的行为和人完全一样，它就有心灵」。这个观点对不对？PP Lab 帮你把它放到实验台上检验：

1. 你先写下自己的判断。
2. 拨动几个开关，改变实验的前提条件，看中间的三维场景怎么变化。
3. 选一个哲学立场（比如功能主义），让它对你的判断提出一条具体的反驳。
4. 你可以回应这条反驳、修改自己的判断，或者保留分歧。
5. 每一次修改都会留下记录，你可以随时回看之前的版本。

它不是一个「问 AI 哲学问题」的聊天框。场景和反驳都围绕你自己写下的判断展开，AI（如果连接了）扮演的是挑毛病的陪练，不是给答案的神谕。

默认的思想实验是「黑箱室」：一个不透明的系统，你只能看到它的输入和输出，看不到内部。你要判断的是：它有没有心智？它的行为能不能被解释？这对应心智哲学和科学技术哲学里的一组经典争论。

## 界面一览

打开页面后，屏幕分成四块：

- **顶栏**：实验标题、白天/夜晚主题切换、「连接 AI」入口、导出按钮。
- **左侧「前提」**：三个开关（可解释性、可验证性、有理由）。每个开关代表实验的一个前提条件。
- **中间「黑箱室」**：一个三维场景。开关变化时，场景里的材质、光线和标注会跟着变。可以切换三个相机角度。如果浏览器不支持三维，会自动换成二维示意图，功能不受影响。
- **右侧「判断与检验」**：写你的主张、选立场、运行探针、处理反驳的地方。
- **底部「反例轨道」**：你的每一次修改都变成一个版本节点，排成一条轨道。点任何节点可以回看当时的完整状态。

手机上这四块会竖着排，都能用。

## 五分钟上手

1. **打开网页**。中间是一个三维黑箱场景，可以用鼠标拖动旋转、滚轮缩放，也可以点相机预设按钮换角度。
2. **拨左侧的开关**。比如关掉「可解释性」，场景里的系统会变得更不透明。注意左侧条件旁的说明文字，它解释这个开关改变了什么。
3. **在右侧写下你的主张**。比如「如果功能完全等价，系统就拥有心智」。这是你自己的判断，没有标准答案。
4. **选一张立场卡**。三张卡分别是功能主义、生物自然主义、机制解释。每张卡写明了这个立场的核心承诺、常见反驳和局限。选中后，左侧会亮起它要检验的那条前提。
5. **点「运行探针」**。系统会从你选的立场出发，对你的主张提出一条异议和一个追问，并且指明它针对的是哪条前提。没连接 AI 时，探针来自内置的立场卡内容；连接 AI 后，由模型现场生成。
6. **处理这条反驳**。三个选择：
   - **回应**：写下你的答辩，探针标记为「已回应」。
   - **修改前提或主张**：改动后写一句修改理由，系统生成一个新版本。
   - **保留异议**：承认分歧存在，不强行达成一致。探针标记为「保留」。
7. **看底部轨道**。每次修改都留下一个带理由的版本。点旧版本可以回溯；回溯不会删除历史，而是生成一个新版本。
8. **（可选）逛星图**。星图把这个实验相关的理论、人物和文献连成一张图。点节点或连线可以看解释和来源出处，大部分链接到斯坦福哲学百科（SEP）等公开资料。
9. **（可选）导出**。顶栏的导出按钮会把你的实验和所有版本存成一个 JSON 文件，可以带走备份。

## 连接 AI（可选）

不连接 AI，网页的全部功能都能用，探针来自内置内容。连接后，探针的异议和追问由大模型根据你的主张、前提和所选立场现场生成，更贴合你写的内容。

你需要一个模型服务商的 API key（相当于密码）。网页本身不收费，但模型调用由服务商按用量计费，费用走你自己的 key。

**怎么连：**

1. 点顶栏的「连接 AI」。
2. 选服务商：DeepSeek、Moonshot（Kimi）、OpenAI，或者自定义（任何兼容 OpenAI 接口的服务）。
3. 粘贴你的 API key。地址和模型名已经按服务商填好，可以改。
4. 点「测试连接」。成功会显示可用模型数量。
5. 点「保存并连接」。顶栏变成「AI 已连接」，之后运行探针就会用模型生成。

**你的 key 安全吗：**

- key 只存在当前标签页的临时存储里，关掉标签页就清除。
- key 不会写进实验数据、导出文件、日志或错误提示。
- 只允许 https 的公网地址；本地地址和内网地址会被拒绝，防止网页被用来探测你的内部网络。

**失败了怎么办：** 如果模型调用失败（网络问题、额度用完、key 失效），系统会自动改用内置探针，并提示「已改用本地探针」，实验不会中断。

**怎么断开：** 打开「连接 AI」弹窗，点「断开连接」，key 立即清除。

## 你的数据存在哪

所有实验数据只存在你自己浏览器的本地存储（IndexedDB）里。没有账号，没有服务器，没有人能看到你的内容。换一台电脑或换一个浏览器，就是从头开始；想带走数据，用导出功能。清除浏览器数据会删掉实验记录，重要内容请先导出。

## 常见问题

**需要哲学基础吗？** 不需要。立场卡和星图都写了人话解释，探针会把反驳指向具体的前提，你可以顺着读。

**AI 说的就是对的吗？** 不是。探针是批评，不是裁决。它可能说得不对，你可以回应、修改或保留异议。系统不声称任何理论被「证明」。

**没有独立显卡能用吗？** 能。三维场景很轻量；不支持 WebGL 的浏览器会自动显示二维示意图。

**手机上能用吗？** 能。界面会竖排，星图在手机上目前是滚动查看。

**导出能再导回来吗？** 暂时不能。导入功能还没做，导出目前用于备份和查看。

**为什么有些星图连线写「尚未找到文献支持」？** 那是推测性的关联，不是有出处的结论。我们把它和文献支持的关系分开标注。

## 还没做的

- 导演模式、逐幕回放、相似性报告、更多场景模板。
- 导出文件的导入。
- 星图桌面端的缩放和拖拽。
- 立场卡和星图的部分文案仍是草案。

## 给开发者

技术栈：Vite 8 + React 19 + TypeScript 7，React Three Fiber / three.js，Zustand（状态与串行写入队列），Zod（数据校验），Dexie / IndexedDB，Tailwind CSS v4。

```bash
npm install
npm run dev        # 本地开发
npm run typecheck  # 类型检查
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览生产构建
```

部署：推送到 `main` 后 GitHub Actions 自动构建并发布到 GitHub Pages（仓库 Settings → Pages 的 Source 设为 GitHub Actions）。

内容文件：

- 场景标题、对象、条件、注释：`src/lib/seed.ts`
- 立场卡与探针文案：`src/lib/content.ts`
- 星图节点、关系、来源：`src/lib/starmap.ts`
- AI 连接与探针生成：`src/lib/ai.ts`

数据模型：SceneSpec 描述实体、条件和条件到实体的绑定；Probe 记录立场、快照、目标前提、异议、回应和来源（本地/AI）；Revision 保存完整快照，回溯生成新版本；StarMap 的中心节点从当前实验现场生成。所有视图共用同一份状态。

图标：`public/icon.png` 与 `public/icon-512.png` 是透明背景点阵图标，按项目原始图标重绘。
